# ML Buscador por Cidade

Ferramenta web para gerar links filtrados por cidade no Mercado Livre, facilitando encontrar vendedores locais.

## 🔗 Acesse online

👉 **https://ricardomedeiros123.github.io/ml-buscador-cidade/**

## Funcionalidades

- Busca por produto + cidade
- Filtros: condição (novo/usado), ordenação, faixa de preço, frete grátis, avaliação mínima
- Importar qualquer cidade colando uma URL do ML com filtro de cidade aplicado
- Gera e abre o link automaticamente no navegador

## Como adicionar novas cidades

1. Faça uma busca no ML e aplique o filtro **"Retirada grátis: Cidade"**
2. Copie a URL completa
3. No app, clique em **"+ Importar URL"** e cole a URL

## Uso local (Python)

```bash
python ml_city_search.py
```
